# خطة التنفيذ

1. تقييد تعيينات التقييم بدور المعلم.
2. إنشاء نطاق أخصائي سنوي وخدمة مركزية مع migration وترحيل قرائي آمن من الجدول القديم.
3. إضافة إدارة الصفوف والفصول إلى حسابات العاملين.
4. إنشاء طلبات تعديل الطالب المعلقة وصفحة مراجعة المدير.
5. إنشاء shell الأخصائي وخدمات القراءة المملوكة للوحدات وصفحات الدخول الرفيعة.
6. تعطيل كتابات وتقارير الأخصائي القديمة وفصل وضع المشرف.
7. إضافة اختبارات العقود وتحديث ADR والذاكرة وسياسة العام الجديد.
8. تشغيل lint والاختبارات والتدقيقات المعمارية والجودة؛ اختبار migration تكامليًا فقط عند توفر قاعدة `_test` صريحة.

## الرجوع

- يمكن إعادة نقاط الدخول القديمة برمجيًا مع إبقاء الجداول الجديدة خاملة.
- لا تحذف migration جدول `specialist_classes`; لذا يمكن إعادة القراءة إليه بعد التحقق من النسخة السابقة.
- طلبات تعديل الطالب لا تغيّر الطالب قبل الاعتماد، لذلك إيقاف المسار لا يحتاج عكس بيانات الطلاب.
