# مواصفة بوابة الأخصائي المقيدة

## الهدف

توفير بوابة أخصائي تشبه واجهة الإدارة، لكن لا تعرض إلا الطلاب والفصول والبيانات التشغيلية الواقعة ضمن الصفوف أو الفصول المسندة للأخصائي في العام الدراسي الحالي.

## المتطلبات الوظيفية

1. صفحة تعيينات التقييم تعرض حسابات المعلمين فقط.
2. يعين المدير صفوف الأخصائي وفصوله من صفحة حسابات العاملين.
3. تعرض بوابة الأخصائي صفحات الطلاب والقوائم والحضور والملفات والبطاقات والتصدير والإحصائيات والحسابات والتقييمات والتقارير والتحليلات وزيارات العيادة ضمن النطاق فقط.
4. لا يستطيع الأخصائي إضافة طالب أو أرشفته أو حذف بيانات تشغيلية.
5. تعديل بيانات طالب ينشئ طلبًا معلقًا. يطبقه المدير أو يرفضه من صفحة العمليات المعلقة، مع كشف التعارض إذا تغيرت القيمة الأصلية.
6. لا يستخدم المشرف دور الأخصائي الفعال، ولا تبقى نقطة كتابة قديمة للأخصائي فعالة.

## معايير القبول

- طلب معرف فصل أو طالب أو معلم خارج النطاق يرفض قبل القراءة.
- أخصائي بلا تعيينات يرى حالة فارغة ولا يرى بيانات المدرسة العامة.
- كل صفحات البوابة المطلوبة تتحقق من جلسة الأخصائي قبل أي معالجة.
- مسارات AJAX القديمة لإضافة/حذف التقييمات أو التقرير القديم ترفض الأخصائي.
- كل كتابة جديدة مدققة ومعاملية، ولا تطبق migration أو اختبار كتابة على قاعدة `educore`.
