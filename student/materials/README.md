## 📂 الملفات الموجودة

### 🔵 الملفات الأساسية (للاستخدام)

| الملف | الوظيفة | الاستخدام |
|-------|---------|-----------|
| **view.php** | الملف الديناميكي الرئيسي | يعرض المواد لأي صف وفصل دراسي |
| **materials_data.json** | قاعدة بيانات المواد | يحتوي على جميع معلومات المواد |
| **index.html** | الصفحة الرئيسية | نقطة البداية للنظام |
| **style.css** | التنسيقات | تصميم جميع الصفحات |
| **script.js** | JavaScript | التفاعلات والخلفية المتحركة |

| الملف | الوظيفة |
|-------|---------|

| **DYNAMIC_MATERIALS_GUIDE.md** | الدليل الكامل للنظام |
| **QUICK_START.md** | دليل البداية السريعة |

| **README.md** | هذا الملف |

### 🟡 المجلدات

| المجلد | المحتوى |
|--------|---------|
| **term1/** | صفحة اختيار الصف للفصل الأول |
| **term2/** | صفحة اختيار الصف للفصل الثاني |
| **archive/** | الملفات القديمة المؤرشفة (26 ملف HTML) |

## 🚀 كيفية الاستخدام

### للمطورين:

#### 1️⃣ إضافة مادة جديدة
افتح `materials_data.json` وأضف:
```json
{"name": "اسم المادة", "file": "اسم الملف.pdf"}
```

#### 2️⃣ تحديث التصميم
عدّل `view.php` فقط - التغييرات ستنطبق على جميع الصفوف تلقائياً!

#### 3️⃣ اختبار النظام
افتح: `test_system.php`

---

### للمستخدمين:

#### الطريقة 1: من الصفحة الرئيسية
```
index.html → اختر الفصل → اختر المرحلة → اختر الصف → حمّل المواد
```

#### الطريقة 2: الرابط المباشر
```
view.php?grade=prim1&term=term1
```

## 🆘 الدعم

### المشاكل الشائعة:

#### ❓ الصفحة لا تعمل؟
- ✅ تأكد من تشغيل XAMPP
- ✅ تحقق من المسار الصحيح
- ✅ راجع ملف `materials_data.json`

#### ❓ JSON غير صحيح؟
- افتح: https://jsonlint.com/
- الصق محتوى `materials_data.json`
- صحح الأخطاء المعروضة

#### ❓ الملفات لا تُحمّل؟
- ✅ تأكد من وجود PDF في `sheets/`
- ✅ تحقق من اسم الملف في JSON
- ✅ راجع المجلد المحدد في `"folder"`
