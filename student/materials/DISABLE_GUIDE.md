# 🔒 دليل تعطيل المواد والترمات - Materials System

## 🎯 نظرة عامة

النظام الآن يدعم **3 مستويات** للتعطيل المؤقت:
1. ✅ تعطيل صف دراسي بالكامل
2. ✅ تعطيل فصل دراسي (ترم) معين
3. ✅ تعطيل مادة واحدة فقط

---

## 📋 كيفية التعطيل

### 1️⃣ تعطيل صف دراسي بالكامل

#### افتح `materials_data.json` وأضف `"enabled": false`:

```json
{
  "grades": {
    "prim4": {
      "name": "Prim 4",
      "folder": "g4",
      "enabled": false,  ← أضف هذا السطر
      "terms": {
        ...
      }
    }
  }
}
```

**النتيجة:**
- ❌ جميع المواد في جميع الترمات لهذا الصف ستكون غير متاحة
- ✅ الطلاب سيرون رسالة "الصف غير متاح مؤقتاً"

---

### 2️⃣ تعطيل فصل دراسي (ترم) معين

#### أضف `"term1_enabled": false` أو `"term2_enabled": false`:

```json
{
  "prim4": {
    "name": "Prim 4",
    "folder": "g4",
    "terms": {
      "term1_enabled": false,  ← لتعطيل الفصل الأول
      "term2_enabled": true,   ← الفصل الثاني متاح (اختياري)
      "term1": [...],
      "term2": [...]
    }
  }
}
```

**النتيجة:**
- ❌ الفصل الأول (Term 1) غير متاح
- ✅ الفصل الثاني (Term 2) متاح
- ✅ رسالة "الفصل الدراسي غير متاح مؤقتاً"

---

### 3️⃣ تعطيل مادة واحدة فقط

#### أضف `"enabled": false` للمادة:

```json
{
  "term1": [
    {
      "name": "Arabic",
      "file": "Arabic G4 - T1 - 2026.pdf"
    },
    {
      "name": "Math",
      "file": "Math G4 - T1 - 2026.pdf",
      "enabled": false  ← المادة معطلة
    },
    {
      "name": "Science",
      "file": "Science G4 - T1 - 2026.pdf"
    }
  ]
}
```

**النتيجة:**
- ❌ مادة Math لن تظهر في القائمة
- ✅ باقي المواد متاحة

---

## 🔄 إعادة التفعيل

### لإعادة تفعيل صف:
```json
"enabled": true   ← أو احذف السطر بالكامل
```

### لإعادة تفعيل ترم:
```json
"term1_enabled": true   ← أو احذف السطر بالكامل
```

### لإعادة تفعيل مادة:
```json
"enabled": true   ← أو احذف السطر بالكامل
```

**ملاحظة:** القيمة الافتراضية هي `true` (متاح)

## 📝 أمثلة عملية

### مثال 1: تعطيل الصف الرابع بالكامل خلال الصيانة

```json
"prim4": {
  "name": "Prim 4",
  "folder": "g4",
  "enabled": false,  ← الصف بالكامل معطل
  "terms": {
    "term1": [...],
    "term2": [...]
  }
}
```

---

### مثال 2: إخفاء الفصل الثاني لحين بداية الترم

```json
"prim5": {
  "name": "Prim 5",
  "folder": "g5",
  "terms": {
    "term1_enabled": true,   ← الفصل الأول متاح
    "term2_enabled": false,  ← الفصل الثاني معطل مؤقتاً
    "term1": [...],
    "term2": [...]
  }
}
```

---

### مثال 3: إخفاء مادة معينة لحين رفع الملف

```json
"term1": [
  {
    "name": "Arabic",
    "file": "Arabic G6 - T1 - 2026.pdf"
  },
  {
    "name": "French",
    "file": "French G6 - T1 - 2026.pdf",
    "enabled": false  ← الملف لم يُرفع بعد
  },
  {
    "name": "Math",
    "file": "Math G6 - T1 - 2026.pdf"
  }
]
```

---

### مثال 4: تعطيل كل الصفوف ما عدا واحد (صيانة عامة)

```json
{
  "grades": {
    "kg1": { "enabled": false, ... },
    "kg2": { "enabled": false, ... },
    "prim1": { "enabled": true, ... },  ← متاح فقط
    "prim2": { "enabled": false, ... },
    "prim3": { "enabled": false, ... }
  }
}
```
