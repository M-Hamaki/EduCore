## 🎯 نظرة عامة

### ما هو النظام؟
نظام ديناميكي موحد يحل محل **26 ملف HTML ثابت** بملف واحد فقط (view.php) + قاعدة بيانات JSON.

### لماذا التحديث؟
| قبل | بعد | الفائدة |
|-----|-----|---------|
| 26 ملف | 1 ملف | 96% أقل |
| ~2,600 سطر | ~100 سطر | 97% أقل |
| تحديث 26 ملف | تحديث ملف واحد | 26× أسرع |
| إضافة صعبة | إضافة فورية | سهل جداً |

### المميزات الرئيسية:
- ✅ **ديناميكي**: ملف واحد لجميع الصفوف
- ✅ **مركزي**: بيانات JSON موحدة
- ✅ **سريع**: تحديثات فورية
- ✅ **آمن**: معالجة أخطاء متقدمة
- ✅ **موثّق**: 7 ملفات توثيق شاملة

## 🚀 كيفية الاستخدام

### للمستخدمين:

#### الطريقة 1: من الواجهة
```
1. افتح: student/materials/index.html
2. اختر الفصل الدراسي (Term 1 أو Term 2)
3. اختر المرحلة (KG, Prim, Prep, Sec)
4. اختر الصف الدراسي
5. حمّل المواد!
```

#### الطريقة 2: رابط مباشر
```
view.php?grade=CODE&term=TERM

أمثلة:
- view.php?grade=prim1&term=term1   ← الأول الابتدائي - فصل 1
- view.php?grade=prim4&term=term2   ← الرابع الابتدائي - فصل 2
- view.php?grade=prep1&term=term1   ← الأول الإعدادي - فصل 1
- view.php?grade=sec1&term=term2    ← الأول الثانوي - فصل 2
```

### للمطورين:

#### عرض صفحة:
```php
// في view.php
$grade = $_GET['grade'];  // prim1, prim4, prep1, ...
$term = $_GET['term'];    // term1 أو term2

// يتم جلب البيانات من JSON تلقائياً
// ويتم عرض الصفحة ديناميكياً
```

## 🔧 استكشاف الأخطاء

### المشكلة 1: الصفحة لا تعمل

#### الحل:
```
✅ تأكد من تشغيل XAMPP (Apache)
✅ تحقق من المسار الصحيح
✅ راجع ملف materials_data.json
```

### المشكلة 2: JSON غير صحيح

#### الحل:
```
1. افتح https://jsonlint.com/
2. الصق محتوى JSON
3. ابحث عن الخط الأحمر
4. صحح الخطأ (غالباً: فاصلة زائدة أو ناقصة)
5. احفظ الملف
```

### المشكلة 3: ملفات PDF لا تُحمّل

#### الحل:
```
✅ تأكد من وجود الملف في sheets/g**/
✅ تحقق من اسم الملف في JSON (حساس لحالة الأحرف)
✅ راجع المجلد المحدد في "folder"
```

### المشكلة 4: صفحة فارغة

#### الحل:
```
✅ افتح test_system.php للتحقق من JSON
✅ تأكد من وجود grade و term في الرابط
✅ راجع سجل الأخطاء في XAMPP
```
