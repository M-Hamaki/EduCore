## 🔗 الروابط والمسارات

### 5. هيكل الروابط

```
/                              → stage_selection.php
/stage_selection.php           → صفحة اختيار المرحلة
/public_portal.php?stage=...   → البوابة العامة
  └─ ?stage=kindergarten      → رياض أطفال
  └─ ?stage=preparatory       → إعدادي
  └─ ?stage=secondary         → ثانوي
/index.php?stage=primary       → تسجيل دخول (ابتدائي)
/student/portal.php            → البوابة الكاملة
  └─ /student/index.php       → نظام المكافآت
  └─ /student/reports/        → التقارير
  └─ /student/materials/      → المواد
  └─ /student/ebook/          → الكتب
  └─ results (external)       → النتائج
```
