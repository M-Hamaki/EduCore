# خطوات تفعيل نظام الصفوف والفصول
## Quick Setup Guide

---

## ⚡ خطوات التنفيذ السريع

### الخطوة 1️⃣: تنفيذ ملف SQL على قاعدة البيانات

#### طريقة 1: باستخدام phpMyAdmin
1. افتح phpMyAdmin من المتصفح: `http://localhost/phpmyadmin`
2. اختر قاعدة البيانات `rewards_db`
3. انقر على تبويب "SQL"
4. افتح ملف `add_grades_system.sql` بمحرر نصوص
5. انسخ المحتوى بالكامل والصقه في نافذة SQL
6. انقر على "تنفيذ" (Go)

#### طريقة 2: من خلال Terminal
```bash
# في PowerShell أو CMD
cd C:\xampp\mysql\bin
.\mysql.exe -u root -p rewards_db < C:\xampp\htdocs\rewards\add_grades_system.sql
```

---

### الخطوة 2️⃣: التحقق من نجاح التنفيذ

#### في phpMyAdmin:
1. افتح قاعدة البيانات `rewards_db`
2. تحقق من وجود جدول جديد باسم `grades`
3. افتح جدول `classes` وتحقق من وجود عمود `grade_id`
4. افتح جدول `grades` وتحقق من وجود 6 صفوف (prim1 إلى prim6)

#### استعلامات التحقق:
```sql
-- التحقق من إنشاء جدول الصفوف
SHOW TABLES LIKE 'grades';

-- عرض بنية جدول الصفوف
DESC grades;

-- عرض الصفوف المدرجة
SELECT * FROM grades;

-- التحقق من إضافة grade_id إلى جدول الفصول
DESC classes;

-- عرض الفصول مع الصفوف المرتبطة
SELECT c.id, c.name, g.grade_name 
FROM classes c 
LEFT JOIN grades g ON c.grade_id = g.id;
```

---

### الخطوة 3️⃣: اختبار الواجهة الإدارية

1. **افتح لوحة تحكم الإدارة:**
   ```
   http://localhost/rewards/admin/
   ```

2. **اختبر صفحة الصفوف الدراسية:**
   - انقر على "الصفوف والفصول" → "الصفوف الدراسية"
   - يجب أن تظهر لك 6 بطاقات للصفوف الستة
   - جرّب إضافة صف جديد
   - جرّب تعديل أحد الصفوف
   - جرّب حذف صف (سيفشل إذا كان يحتوي على فصول)

3. **اختبر صفحة الفصول:**
   - انقر على "الصفوف والفصول" → "الفصول"
   - يجب أن تظهر لك الفصول مع عمود "الصف الدراسي"
   - جرّب إضافة فصل جديد وربطه بصف
   - جرّب تعديل فصل موجود وتغيير الصف الدراسي

---

### الخطوة 4️⃣: ربط الفصول الموجودة بالصفوف

إذا كانت لديك فصول موجودة بالفعل:

#### الطريقة التلقائية (تم تنفيذها في SQL):
```sql
-- تم تنفيذ هذه الأوامر تلقائياً في add_grades_system.sql
UPDATE classes SET grade_id = 1 WHERE name LIKE '%1%';
UPDATE classes SET grade_id = 2 WHERE name LIKE '%2%';
-- ... إلخ
```

#### الطريقة اليدوية (من الواجهة):
1. اذهب إلى "الصفوف والفصول" → "الفصول"
2. لكل فصل، انقر على زر "تعديل" (أيقونة القلم)
3. اختر الصف الدراسي المناسب من القائمة المنسدلة
4. احفظ التغييرات

## 🐛 حل المشاكل الشائعة

### مشكلة: "Table 'grades' already exists"
**الحل:** الجدول موجود بالفعل، يمكنك تخطي هذا الخطأ أو حذف الجدول أولاً:
```sql
DROP TABLE IF EXISTS grades;
```

### مشكلة: "Column 'grade_id' already exists"
**الحل:** العمود موجود بالفعل، يمكنك تخطي هذا الخطأ.

### مشكلة: صفحة grades.php تعطي خطأ 404
**الحل:** 
1. تأكد من وجود ملف `admin/grades.php`
2. تأكد من الصلاحيات (chmod 644 في Linux)
3. أعد تشغيل Apache

### مشكلة: لا تظهر القائمة المنسدلة في classes.php
**الحل:**
1. تأكد من تنفيذ استعلام الصفوف في الكود
2. تحقق من وجود بيانات في جدول `grades`
3. تحقق من سجل الأخطاء PHP

### مشكلة: Foreign key constraint fails
**الحل:**
```sql
-- إزالة المفتاح الأجنبي القديم
ALTER TABLE classes DROP FOREIGN KEY fk_classes_grade;

-- إعادة إضافته
ALTER TABLE classes
ADD CONSTRAINT fk_classes_grade 
FOREIGN KEY (grade_id) REFERENCES grades(id) 
ON DELETE SET NULL ON UPDATE CASCADE;
```

## 🎯 ما بعد التنفيذ

بعد إتمام التنفيذ بنجاح، يمكنك:

1. **تخصيص الصفوف:** تعديل أسماء الصفوف لتتناسب مع مدرستك
2. **إضافة مراحل أخرى:** إضافة صفوف إعدادية أو ثانوية
3. **ربط الفصول:** التأكد من أن جميع الفصول مرتبطة بالصفوف الصحيحة
4. **استخدام التقارير:** استفد من التصنيف الجديد في التقارير
