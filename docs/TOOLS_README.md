# 🛠️ أدوات صيانة وإصلاح نظام الإدارة المدرسية

## 📌 الملفات المتاحة لحل المشاكل

| الملف | الغرض | متى تستخدمه |
|------|-------|------------|
| `fix_settings.php` | إصلاح جدول settings تلقائياً | عند مشاكل في إعدادات النظام |
| `check_settings.php` | فحص تفصيلي لجدول settings | للتشخيص والمراجعة |
| `install8498.php?upgrade=1` | ترقية قاعدة البيانات | بعد تحديث النظام |

## 🚨 مشكلة شائعة: التقييمات لا تُفعّل

### الأعراض:
- الضغط على "تفعيل التقييمات في كل الأوقات" لا يعمل
- الإعدادات لا تُحفظ
- رسائل خطأ عند فتح صفحة إعدادات النظام

### الحل السريع:
```
1. افتح المتصفح واذهب إلى:
   http://localhost/rewards1/fix_settings.php

2. انتظر حتى يكتمل الإصلاح التلقائي

3. اضغط "الذهاب إلى إعدادات النظام"

4. فعّل الخيار المطلوب واحفظ
```
