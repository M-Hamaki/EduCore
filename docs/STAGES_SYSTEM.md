# نظام إدارة المراحل الدراسية

## نظرة عامة
تم إنشاء نظام شامل لإدارة المراحل الدراسية يسمح بالتحكم في الخدمات المتاحة لكل مرحلة.

## المكونات الرئيسية

### 1. قاعدة البيانات

#### جدول `stages`
```sql
- id: معرف فريد
- stage_name: اسم المرحلة بالعربية
- stage_name_en: اسم المرحلة بالإنجليزية
- stage_code: كود فريد (primary, preparatory, secondary, kindergarten)
- stage_order: ترتيب العرض
- services: JSON يحتوي على الخدمات المتاحة
- status: حالة المرحلة (active/inactive)
```

#### الخدمات المتاحة
- `rewards`: نظام المكافآت
- `reports`: التقارير الشهرية
- `materials`: المواد التعليمية
- `ebooks`: الكتب الإلكترونية
- `results`: النتائج

#### تحديث جدول `grades`
- تمت إضافة عمود `stage_id` لربط كل صف بمرحلته
- Foreign Key يربط grades.stage_id بـ stages.id

### 2. الملفات المضافة/المعدلة

#### الملفات الجديدة
- `create_stages_system.sql`: سكريبت إنشاء النظام
- `admin/stages.php`: صفحة إدارة المراحل الدراسية
- `STAGES_SYSTEM.md`: هذا الملف

#### الملفات المعدلة
- `admin/grades.php`: 
  - إضافة dropdown لاختيار المرحلة
  - عرض المرحلة في جدول الصفوف
  
- `student/portal.php`:
  - قراءة الخدمات من قاعدة البيانات
  - عرض الكروت بناءً على المرحلة
  
- `includes/admin_header.php`:
  - إضافة رابط إدارة المراحل في القائمة

### 3. كيفية الاستخدام

#### للأدمن:

1. **إدارة المراحل** (`admin/stages.php`):
   - عرض جميع المراحل مع عدد الصفوف المرتبطة
   - إضافة مرحلة جديدة
   - تعديل مرحلة موجودة
   - تفعيل/تعطيل مرحلة
   - حذف مرحلة (إذا لم تكن مرتبطة بصفوف)
   - تحديد الخدمات المتاحة لكل مرحلة

2. **إدارة الصفوف** (`admin/grades.php`):
   - اختيار المرحلة عند إضافة/تعديل صف
   - عرض المرحلة في قائمة الصفوف

#### للطلاب:

- عند تسجيل الدخول، يتم قراءة الخدمات المتاحة من:
  ```
  Student → Class → Grade → Stage → Services (JSON)
  ```
- يتم عرض الكروت فقط للخدمات المفعلة في المرحلة

### 4. المراحل الافتراضية

تم إنشاء 4 مراحل افتراضية:

1. **رياض الأطفال** (kindergarten):
   - الخدمات: Materials, Results

2. **المرحلة الابتدائية** (primary):
   - الخدمات: Rewards, Reports, Materials, E-Books, Results

3. **المرحلة الإعدادية** (preparatory):
   - الخدمات: Reports, Materials, E-Books, Results

4. **المرحلة الثانوية** (secondary):
   - الخدمات: Reports, Materials, E-Books, Results

### 5. الميزات

✅ **مرونة عالية**: يمكن تخصيص الخدمات لكل مرحلة بسهولة
✅ **ربط ديناميكي**: الصفوف مرتبطة بالمراحل تلقائياً
✅ **حماية البيانات**: لا يمكن حذف مرحلة مرتبطة بصفوف
✅ **تعطيل بدلاً من الحذف**: الحفاظ على سلامة البيانات
✅ **واجهة سهلة**: Checkboxes لتحديد الخدمات
✅ **تحديث تلقائي**: التعديلات تنعكس فوراً على الطلاب

### 6. ملاحظات مهمة

- جميع الصفوف الموجودة تم ربطها تلقائياً بالمراحل المناسبة
- النظام يدعم إضافة مراحل جديدة بسهولة
- يمكن تعديل الخدمات المتاحة في أي وقت
- الطلاب يرون التغييرات فوراً بعد تسجيل الدخول مرة أخرى

### 7. التطوير المستقبلي

يمكن إضافة:
- صلاحيات مختلفة حسب المرحلة
- تقارير خاصة بكل مرحلة
- إعدادات مخصصة لكل مرحلة
- رسائل ترحيبية مختلفة
- ألوان وشعارات مخصصة
