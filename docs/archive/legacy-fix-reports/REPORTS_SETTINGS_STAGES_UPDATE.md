# تحديثات صفحة إعدادات التقارير
**التاريخ:** 12 نوفمبر 2025

## التغييرات المطبقة

### 1. إزالة العنوان المكرر ✅
- **المشكلة:** كان يوجد عنوانين للصفحة في الأعلى
- **الحل:** تم إلغاء العنوان الداخلي "إعدادات التقارير الشهرية" والاعتماد على عنوان الصفحة الأساسي فقط

### 2. تصغير صندوق المعلومات المهمة ✅
- **المشكلة:** صندوق "معلومات مهمة" كان يأخذ مساحة كبيرة جداً
- **الحل:** 
  - تقليل padding من 20px إلى 12px 15px
  - تصغير الخط إلى 0.9rem
  - تقليل border من 5px إلى 3px
  - إزالة التدرج اللوني واستخدام خلفية رمادية بسيطة (#f8f9fa)
  - تقليل المسافات بين العناصر

### 3. تصنيف الصفوف حسب المراحل الدراسية ✅
- **المشكلة:** جميع الصفوف كانت تحت بعضها مباشرة بدون تصنيف
- **الحل:**
  - إضافة عمود `stage` لجدول `grades` في قاعدة البيانات
  - تصنيف الصفوف إلى 3 مراحل:
    * 🧒 **المرحلة الابتدائية** (primary): prim1-6
    * 🎓 **المرحلة الإعدادية** (preparatory): prep1-3
    * 🎓 **المرحلة الثانوية** (secondary): sec1-3
  - إضافة عناوين المراحل بأيقونات مميزة وتنسيق أزرق
  - فقط أول صف في كل مرحلة يكون مفتوحاً افتراضياً

### 4. تحسينات JavaScript ✅
- تحديث دالة `toggleGradeSection` للعمل مع تصنيف المراحل
- حفظ حالة الطي/الفتح في `localStorage` لكل صف
- فتح أول صف في كل مرحلة افتراضياً (prim1, prep1, sec1)

## الملفات المعدلة
1. `admin/reports_settings.php` - الصفحة الرئيسية
2. `add_stage_to_grades.php` - Script إضافة عمود المرحلة (مرة واحدة)
3. `add_stage_column.sql` - SQL لإضافة العمود (اختياري)

## الملفات الجديدة
- `add_stage_to_grades.php` - Script PHP لتحديث قاعدة البيانات
- `add_stage_column.sql` - SQL لإضافة عمود stage
- `REPORTS_SETTINGS_STAGES_UPDATE.md` - هذا الملف

## قاعدة البيانات
```sql
ALTER TABLE `grades` 
ADD COLUMN `stage` VARCHAR(20) DEFAULT 'primary' AFTER `grade_code`;

UPDATE `grades` SET `stage` = 'primary' WHERE `grade_code` LIKE 'prim%';
UPDATE `grades` SET `stage` = 'preparatory' WHERE `grade_code` LIKE 'prep%';
UPDATE `grades` SET `stage` = 'secondary' WHERE `grade_code` LIKE 'sec%';
```

## الاختبار
✅ تم تنفيذ `add_stage_to_grades.php` بنجاح
✅ تم إضافة عمود `stage` لـ 12 صف دراسي
✅ تم تحديث المراحل بشكل صحيح
