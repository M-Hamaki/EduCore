# تحديث صفحة إعدادات التقارير - جلب الصفوف ديناميكياً

## 📅 تاريخ التحديث: 2025-11-10

---

## ❓ السؤال

> **الآن في صفحة إعدادات التقارير يظهر لدي مجموعة من الصفوف للتحكم في تقاريرها هل هذه هي الصفوف الموجودة حالياً في النظام أم أنها ثابتة؟**
> 
> **وماذا لو قمت بإضافة صف جديد من صفحة إدارة الصفوف هل سيظهر في صفحة إعدادات التقارير؟**

---

## ✅ الإجابة

### 🔴 **المشكلة السابقة:**
كانت الصفوف **ثابتة** في الكود ولا تتحدث تلقائياً!

```php
// القائمة الثابتة القديمة ❌
$grades = [
    'prim1' => 'الصف الأول الابتدائي',
    'prim2' => 'الصف الثاني الابتدائي',
    'prim3' => 'الصف الثالث الابتدائي',
    'prim4' => 'الصف الرابع الابتدائي',
    'prim5' => 'الصف الخامس الابتدائي',
    'prim6' => 'الصف السادس الابتدائي'
];
```

**النتيجة:** إذا أضفت صف سابع أو ثامن من صفحة إدارة الصفوف، **لن يظهر** في إعدادات التقارير!

---

### 🟢 **الحل الجديد:**
الآن يتم جلب الصفوف **ديناميكياً** من جدول `grades` في قاعدة البيانات!

```php
// الجلب الديناميكي الجديد ✅
$grades_query = "SELECT id, grade_name, grade_code FROM grades ORDER BY grade_order";
$grades_stmt = $db->prepare($grades_query);
$grades_stmt->execute();
$grades = $grades_stmt->fetchAll(PDO::FETCH_ASSOC);
```

**النتيجة:** 
- ✅ أي صف جديد تضيفه من صفحة إدارة الصفوف سيظهر **تلقائياً** في إعدادات التقارير
- ✅ الصفوف مرتبة حسب `grade_order`
- ✅ تستخدم `grade_code` كمفتاح و `grade_name` كعنوان

---

## 🔧 التعديلات التقنية

### 1️⃣ **تحديث دالة `loadConfig()`**

**القديم:**
```php
return [
    'reports_enabled' => true,
    'databases' => [
        'prim1' => ['enabled' => true, 'active_month' => '', 'months' => []],
        'prim2' => ['enabled' => true, 'active_month' => '', 'months' => []],
        // ... ثابتة
    ]
];
```

**الجديد:**
```php
// جلب الصفوف من قاعدة البيانات
global $db;
$databases = [];

try {
    $grades_query = "SELECT id, grade_code FROM grades ORDER BY grade_order";
    $grades_stmt = $db->prepare($grades_query);
    $grades_stmt->execute();
    
    while ($grade = $grades_stmt->fetch(PDO::FETCH_ASSOC)) {
        $databases[$grade['grade_code']] = [
            'enabled' => true, 
            'active_month' => '', 
            'months' => []
        ];
    }
} catch (Exception $e) {
    // في حالة فشل الاتصال، استخدم الإعدادات القديمة
    $databases = [...]; // الإعدادات الافتراضية
}

return [
    'reports_enabled' => true,
    'databases' => $databases
];
```

### 2️⃣ **تحديث حلقة عرض الصفوف**

**القديم:**
```php
$grades = [
    'prim1' => 'الصف الأول الابتدائي',
    'prim2' => 'الصف الثاني الابتدائي',
    // ... قائمة ثابتة
];

foreach ($grades as $grade_key => $grade_name):
```

**الجديد:**
```php
// جلب من قاعدة البيانات
$grades_query = "SELECT id, grade_name, grade_code FROM grades ORDER BY grade_order";
$grades_stmt = $db->prepare($grades_query);
$grades_stmt->execute();
$grades = $grades_stmt->fetchAll(PDO::FETCH_ASSOC);

foreach ($grades as $grade):
    $grade_key = $grade['grade_code'];   // مثل: prim1, prim2
    $grade_name = $grade['grade_name'];  // مثل: الصف الأول الابتدائي
    
    // التأكد من وجود إعدادات لهذا الصف
    if (!isset($config['databases'][$grade_key])) {
        $config['databases'][$grade_key] = [
            'enabled' => true, 
            'active_month' => '', 
            'months' => []
        ];
    }
```

- ❌ الصفوف ثابتة في الكود (6 صفوف فقط)
- ❌ لا يمكن إضافة صفوف جديدة بدون تعديل الكود
- ❌ يتطلب تعديل يدوي في `reports_settings.php`

### ✨ **بعد التحديث:**
- ✅ الصفوف ديناميكية من قاعدة البيانات
- ✅ إضافة صف جديد في إدارة الصفوف = ظهور تلقائي في إعدادات التقارير
- ✅ لا حاجة لتعديل الكود
- ✅ يدعم أي عدد من الصفوف (ابتدائي، متوسط، ثانوي، إلخ)

## ⚠️ ملاحظات مهمة

### 1. **الاعتماد على `grade_code`:**
- يُستخدم `grade_code` كمفتاح في ملف الإعدادات
- **يجب** أن يكون `grade_code` فريداً لكل صف
- **مهم:** لا تغير `grade_code` بعد إنشاء الصف لأنه مرتبط بالإعدادات المحفوظة

### 2. **التوافقية العكسية:**
- الكود يحتوي على `try-catch` للتعامل مع الأخطاء
- إذا فشل الاتصال بقاعدة البيانات، سيستخدم القائمة الافتراضية
- يضمن عدم تعطل الصفحة

### 3. **الإعدادات المحفوظة:**
- إذا كان لديك إعدادات محفوظة للصفوف القديمة، ستبقى كما هي
- الصفوف الجديدة تحصل على إعدادات افتراضية
- يمكنك تعديل إعدادات الصفوف الجديدة من الصفحة مباشرة
