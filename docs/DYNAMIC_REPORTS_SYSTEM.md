## 🎯 الميزات الجديدة

### 1. حقل جديد في جدول `grades`
- **اسم الحقل**: `reports_db_prefix`
- **النوع**: VARCHAR(20)
- **الوصف**: يربط الصف بقاعدة بيانات التقارير (مثل: prim1, prep2, sec3)

### 2. إدارة من واجهة الأدمن
تم إضافة حقل "ربط التقارير" في صفحة إدارة الصفوف (`admin/grades.php`) يتيح:
- اختيار قاعدة بيانات التقارير من قائمة منسدلة
- عرض حالة الربط في جدول الصفوف
- تعديل الربط في أي وقت

### 3. الخيارات المتاحة
#### المرحلة الابتدائية:
- `prim1` - الصف الأول الابتدائي
- `prim2` - الصف الثاني الابتدائي
- `prim3` - الصف الثالث الابتدائي
- `prim4` - الصف الرابع الابتدائي
- `prim5` - الصف الخامس الابتدائي
- `prim6` - الصف السادس الابتدائي

#### المرحلة الإعدادية:
- `prep1` - الصف الأول الإعدادي
- `prep2` - الصف الثاني الإعدادي
- `prep3` - الصف الثالث الإعدادي

#### المرحلة الثانوية:
- `sec1` - الصف الأول الثانوي
- `sec2` - الصف الثاني الثانوي
- `sec3` - الصف الثالث الثانوي

## 🔍 استعلامات مفيدة

### عرض جميع الصفوف المرتبطة بالتقارير:
```sql
SELECT id, grade_name, reports_db_prefix 
FROM grades 
WHERE reports_db_prefix IS NOT NULL 
ORDER BY grade_order;
```

### عرض الفصول والصفوف والربط:
```sql
SELECT 
    c.id AS class_id,
    c.name AS class_name,
    g.grade_name,
    g.reports_db_prefix,
    COUNT(DISTINCT u.id) AS students_count
FROM classes c
JOIN grades g ON c.grade_id = g.id
LEFT JOIN users u ON u.class_id = c.id AND u.role = 'student'
GROUP BY c.id, c.name, g.grade_name, g.reports_db_prefix
ORDER BY g.grade_order, c.name;
```
