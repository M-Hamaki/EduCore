# EduCore Roadmap

This roadmap is directional. Priorities may change as contributors, schools, and maintainers validate real-world needs.

## 2026–2027 Roadmap

### AI

- AI-assisted lesson planning
- Question-bank generation
- Arabic/English differentiated content
- Policy and document search
- Reporting assistance
- Clear data-minimization and human-review controls for AI features

### Engineering

- Expand automated and role-focused testing
- Modularize legacy components incrementally
- Improve API and service boundaries
- Accessibility and RTL improvements
- Security hardening and dependency maintenance
- Documented Docker and deployment options

### Open Source

- Contributor documentation and issue templates
- Synthetic demo dataset and public integration guides
- More localization and translation support
- Reusable Microsoft 365 / Teams setup guides
- Release notes, changelog, and reproducible release checks
